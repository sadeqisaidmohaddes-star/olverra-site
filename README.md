# Olverra

Hand carved olive wood from Tunisia. Marketing site.

Carved by women artisans. Sold in person at New York markets.

## What is here

- `index.html` — the whole site, one file
- `img/` — product photos used on the page

To put it online, upload the `index.html` file and the `img` folder to any web host, or point a static host (GitHub Pages, Netlify, Cloudflare Pages) at this repo.
